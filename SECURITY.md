# Security

This kit lets an AI drive the creative apps on your computer and read and write
files, so its security matters. Thank you for looking.

## Reporting a vulnerability

Please report privately, through GitHub's "Report a vulnerability" button on this
repository's Security tab. Don't open a public issue for a security problem.

Include what you did, what happened, and what you expected. We'll answer within a
week and keep you posted until it's fixed.

## What counts

Especially welcome:

- a way for edit code to reach outside the document without the script check
  reporting it;
- a way for a file tool to write outside the folder it was given, follow a link out
  of it, or overwrite an existing file;
- anything that makes the MCP server or the bridge reachable from another user or
  another machine;
- anything that sends data off the computer.

The script check is a seatbelt, not a sandbox: a report that clever code can hide
from a text scan is useful, but approvals in your AI app are the real brake.

## Supported versions

Only the latest release gets security fixes.
